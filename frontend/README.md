# Frontend (HTML/CSS/JS)

Чистая статика, без сборщиков — на старте этого достаточно.

## Запуск локально

Открывать `index.html` напрямую через `file://` нельзя — `fetch()` к
backend не будет работать из-за ограничений браузера. Нужен любой
локальный статический сервер, например:

```bash
cd frontend
python -m http.server 5500
```

Откройте `http://127.0.0.1:5500`. Убедитесь, что в `backend/.env`
`ALLOWED_ORIGINS` включает этот адрес.

## Структура

```
index.html   # форма загрузки + блок результата
css/styles.css
js/app.js     # запрос к backend, рендер score и советов
```

Стили — через Tailwind CDN (`<script src="https://cdn.tailwindcss.com">`
в `index.html`). Для продакшена стоит перейти на Tailwind CLI/сборку,
чтобы не тянуть CDN-версию на каждый запрос, но для разработки и
обучения CDN — самый быстрый способ начать.
