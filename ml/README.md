# ML — дообучение модели матчинга

`train_in_colab.py` — не скрипт для локального запуска, а код,
который нужно скопировать ячейками в Google Colab (там есть бесплатный
GPU, который и нужен для обучения — см. обзор в роадмапе).

После обучения:

1. Скачайте папку с весами модели (`resume-matcher-minilm`).
2. Переименуйте/поместите её как `backend/ml/model/`.
3. В `backend/.env` укажите `EMBEDDING_MODEL_PATH=./ml/model`.

Пока модели нет — backend автоматически использует базовую
`all-MiniLM-L6-v2` (см. `app/services/embeddings.py`), так что можно
разрабатывать и тестировать остальной пайплайн, не дожидаясь обучения.
